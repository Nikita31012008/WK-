# VK Styles - Бесплатное расширение для кастомизации ВКонтакте

![VK Styles](https://img.shields.io/badge/VK%20Styles-1.0.0-blue)
![Chrome](https://img.shields.io/badge/Chrome-✓-green)
![Firefox](https://img.shields.io/badge/Firefox-Coming%20Soon-yellow)

**VK Styles** — это мощное бесплатное расширение для браузера, которое позволяет полностью кастомизировать внешний вид ВКонтакте.

## ✨ Основные функции

### 🌙 Темы оформления
- **Тёмная тема** — удобна для работы в тёмное время суток
- **Лёгкая тема** — чистый и свежий дизайн
- **По умолчанию** — оригинальный внешний вид ВК

### 🎨 Цветовые схемы
Выбирайте из 6 готовых цветовых палитр:
- 🔵 Синяя (по умолчанию)
- 🟣 Фиолетовая
- 🟢 Зелёная
- 🔴 Красная
- 🟠 Оранжевая
- 🩷 Розовая

### 🔧 Дополнительные опции
- **Компактный режим** — уменьшает размер элементов интерфейса
- **Скрыть рекомендации** — удаляет рекомендуемые посты и друзей
- **Скрыть объявления** — блокирует всю рекламу на сайте
- **Скрыть истории** — убирает ленту историй

## 📦 Установка

### Chrome/Chromium
1. Скачайте или клонируйте этот репозиторий
2. Откройте `chrome://extensions/`
3. Включите режим разработчика (правый верхний угол)
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с проектом

### Firefox
Скоро будет доступно на Firefox Add-ons!

## 🚀 Использование

1. Нажмите на иконку расширения в браузере
2. Включите нужные опции
3. Выберите цветовую схему
4. Все изменения применяются мгновенно!

